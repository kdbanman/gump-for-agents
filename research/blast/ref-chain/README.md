# blast/ref-chain

Referee of the `chain` arm's Lean formalisation (`research/blast/lean/mathlib/GumpMath/Chain*.lean`,
`notes/chain.md`, `statements_chain.json`). The account is `REVIEW.md`: verdict per group of theorems, defects
D1–D7 ranked with compiled Lean examples, the independent geometry and numbers, and "Not checked".
Scripts and Lean files are listed at the end of `REVIEW.md`; each `.out` file is the output of the script of the
same name.
