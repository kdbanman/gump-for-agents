# blast/ref-chain

Referee of the `chain` arm's Lean formalisation (`research/blast/lean/mathlib/GumpMath/Chain*.lean`,
`notes/chain.md`, `statements_chain.json`) and, in a second review, of its repairs and of the Link modules
(`GumpMath/Link*.lean`, `notes/link.md`, `statements_link.json`). The account is `REVIEW.md`: verdict per group of
theorems, defects D1–D7 with compiled Lean examples (all closed by the second review), the independent geometry and
numbers, and "Not checked" for each review. Scripts and Lean files are listed at the end of each review; each `.out`
file is the output of the script of the same name.
